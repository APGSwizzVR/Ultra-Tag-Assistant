# Ultra Tag Assistant

Discord bot for Ultra Tag.

## Hosting

Startup file: index.js

Start command: npm start

Required environment variables:
- DISCORD_TOKEN
- CLIENT_ID

Optional:
- GUILD_ID
- ACTIVITY_CHANNEL_ID
- LOG_CHANNEL_ID
- WELCOME_CHANNEL_ID
- WELCOME_ROLE_ID
- ACTIVITY_HOUR
- ACTIVITY_MINUTE
- ACTIVITY_EMOJI
- ACTIVITY_REQUIRED
- DATABASE_PATH

The bot is designed for a small hosting limit and starts with a 192 MB Node heap cap.
